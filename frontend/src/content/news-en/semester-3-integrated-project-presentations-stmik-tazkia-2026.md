On Friday, February 13, 2026, semester 3 students of the [Information Systems](/en/programs/information-systems) program at STMIK Tazkia presented five applications they built during one semester at the Tazkia International Class in Sentul. These five applications are the result of an **Integrated Project** that combines four courses simultaneously:

- **MISI.304** — Information Systems Analysis and Design
- **MISI.301** — Integrated Database Management
- **MISI.302** — Web-Based Information Systems
- **MISI.303** — Systems Integration and Deployment

Each team worked with real clients, analyzed requirements, designed systems, implemented applications, and deployed them to production servers. All applications are publicly accessible via the internet.

## 1. Sapa Tazkia — AI Campus Chatbot

| | |
|---|---|
| **Client** | STMIK Tazkia |
| **URL** | [sapa.tazkia.ac.id](https://sapa.tazkia.ac.id) |
| **Tech Stack** | Node.js, React, MySQL, Qdrant (vector DB), Redis |
| **GitHub** | [Code](https://github.com/IchsanJunaedi/Sapa-Tazkia) · [Docs](https://github.com/IchsanJunaedi/sapa-tazkia-documents) |

![Sapa Tazkia Presentation](/images/news/DSC_8124.jpg)

Sapa Tazkia is a chatbot based on Retrieval-Augmented Generation (RAG) that answers campus-related questions using official documents as its data source. The system embeds user questions, searches for relevant documents via Qdrant, then sends the context to an LLM to generate accurate answers.

Key features:
- RAG chatbot with campus document data source
- Student authentication integrated with academic database
- Grade and GPA data access
- Automatic transcript download in PDF format
- Rate limiting and chat history

## 2. Lingkar Warga — RT/RW (Neighborhood) Management

| | |
|---|---|
| **Client** | RT/RW Chairman |
| **URL** | [rtrw.demo.tazkia.ac.id](https://rtrw.demo.tazkia.ac.id) |
| **Tech Stack** | Express.js, Flutter, PostgreSQL, Docker |
| **GitHub** | [Code](https://github.com/azmttqi/Aplikasi-Manajemen-RT-RW) · [Docs](https://github.com/azmttqi/Project-Manajemen-RT-RW-Document) |

![Lingkar Warga Presentation](/images/news/DSC_8130.jpg)

Lingkar Warga is a digital neighborhood administration platform that replaces manual resident data collection, account verification, and reporting processes. The application is built with Flutter, enabling it to run on both web and mobile from a single codebase. The backend is containerized with Docker Compose alongside a PostgreSQL database.

Key features:
- Digital resident data collection
- Account verification system with SMTP email
- Self-service reporting by residents
- Multi-level RT/RW data management
- Containerized deployment with Docker Compose

## 3. Mutaba'ah App — Student Worship Monitoring

| | |
|---|---|
| **Client** | STMIK Tazkia |
| **URL** | [ibadah.demo.tazkia.ac.id](https://ibadah.demo.tazkia.ac.id) |
| **Tech Stack** | Express.js, MongoDB Atlas, React, Chart.js |
| **GitHub** | [Code](https://github.com/runaisyah1337/ProjectWebsite_Mutabaah-Mahasiswa) · [Docs](https://github.com/PatoyUhuy/Mutaba-ah_Mahasiswa_Docs) |

![Mutaba'ah App Presentation](/images/news/DSC_8136.jpg)

A daily worship monitoring system (mutaba'ah) that digitizes the weekly student worship evaluation process. Students fill in 9 worship indicators each week, and the system automatically calculates scores. Data is locked every Sunday at 11:59 PM WIB (Western Indonesia Time) to maintain integrity.

Key features:
- Self-service form with 9 worship indicators
- Automated scoring (score 1-3 per indicator, max 27/week)
- Dashboard visualization with bar and line charts
- Student, mentor, and admin roles
- Smart search across mentoring groups
- Auto-locking data per period

Key features:
- Customer onboarding (digital KYC)
- Account management and real-time balance
- Inter-account fund transfers
- Bill payments
- Transaction history and statement reports (PDF/CSV)
- Multi-factor authentication

## Integrated Projects: Learning from Real Clients

The [project-based learning](/en/about) model at STMIK Tazkia requires students to work on real-client projects from the early semesters. This semester 3 integrated project combines four courses into a single deliverable, so students experience the complete software development cycle: from requirements analysis, database design, web implementation, to production server deployment.

The five projects above demonstrate a wide variety of tech stacks — from React + Node.js, Flutter + Express, to Spring Boot + Thymeleaf — tailored to each client's needs. All applications have been deployed and are publicly accessible, not just assignments that stop at localhost.
